# ToDo App: Implementación con Extreme Programming (XP)

Este proyecto es una aplicación de gestión de tareas desarrollada bajo los principios de **Extreme Programming (XP)**, priorizando la simplicidad, la retroalimentación constante y la calidad del código mediante pruebas.

##  Descripción del Proyecto
Una herramienta ligera de productividad construida con JavaScript puro (Vanilla JS), diseñada para demostrar la aplicación práctica de metodologías ágiles en el desarrollo frontend.

##  Stack Tecnológico y Metodología
* **Lenguaje:** JavaScript (ES6+)
* **Interfaz:** HTML5 & CSS3
* **Metodología:** Extreme Programming (XP)
    * **TDD (Test Driven Development):** El ciclo de desarrollo se basó en la creación de pruebas antes del código funcional.
    * **Diseño Simple:** Implementación de funcionalidades esenciales sin sobreingeniería.

##  Funcionalidades Principales
* **Gestión de Tareas:** Creación, visualización y persistencia de actividades.
* **Estado de Tareas:** Marcado de tareas completadas para seguimiento de progreso.
* **Limpieza de Datos:** Eliminación selectiva de registros.

##  Estrategia de Pruebas (TDD)
Siguiendo los valores de XP, el proyecto incluye validaciones críticas para asegurar la integridad de la aplicación:
1. **Validación de entradas:** Prevención de registros vacíos.
2. **Integridad de inserción:** Verificación de que cada tarea se renderice correctamente.
3. **Gestión de memoria:** Confirmación de la eliminación correcta de registros.
